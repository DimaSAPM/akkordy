# Аккорды

Офлайн-каталог аккордов из Rocksmith 2014 Chord Book для Android: поиск, фильтры, избранное, подборки и режим «на экран» с несколькими аккордами сразу.

## Как получить APK

Каждый push в `main` собирает подписанный APK через GitHub Actions. Готовый файл лежит в разделе **Releases → latest → Akkordy.apk**.

## Устройство

- `app/src/main/assets/www/` — само приложение (HTML, картинки аккордов, шрифт), работает без интернета.
- `MainActivity.java` — WebView, который открывает эти файлы, плюс системные функции: не гасить экран, полноэкранный режим, кнопка «Назад», отправка кода подборок.
- Ключ подписи хранится в секретах репозитория (`KEYSTORE_B64`, `KEYSTORE_PASS`). Без того же ключа новые версии не встанут поверх старой.
